# Dimeric Docking Benchmarks

PPInsight's default batch workflow is a two-partner docking workflow. It is
appropriate for the single receptor-VEGFA interface benchmark used by the
VEGFR1 and VEGFR2 jobs, but it is not a full biological-assembly benchmark.

## Why batch is not the cause

Running engines outside `ppinsight batch` does not by itself make a dimeric
benchmark possible. Batch calls the same engine adapters used by the individual
commands. In particular, the restraint-free HADDOCK adapter combines multi-chain
partners into one logical receptor chain and one logical ligand chain so that
HADDOCK can run its two-body protocol reliably. That normalization is useful for
the default workflow, but it removes the chain-level topology needed to compare
a predicted $2{:}2$ complex directly with a four-chain native assembly.

## VEGFA receptor references

For a dimer-aware VEGFR1 benchmark, biological assembly 1 of 1FLT contains:

- VEGFA dimer: chains `V` and `W`.
- VEGFR1 dimer: chains `X` and `Y`.

VEGFR2 assembly 1 of 3V2A is also a $2{:}2$ biological assembly. Its second
receptor-ligand copy is generated by biological-assembly symmetry, so a usable
multichain reference must first apply the assembly transformations rather than
reusing only the deposited `R` and `A` coordinate chains.

## Requirements for a full $2{:}2$ benchmark

A dimer-aware workflow must deliberately preserve each partner's chain
composition through preparation, docking, and DockQ chain mapping. It needs:

1. A materialized biological assembly with both VEGFA and receptor copies.
2. Engine-specific multichain partner preparation that does not collapse the
   receptor dimer or ligand dimer into a single chain.
3. A documented DockQ chain mapping between the predicted and native four-chain
   assemblies.
4. Separate validation for each supported engine before treating its results as
   comparable to the default single-interface benchmark.

Until that protocol exists, report the current workflow as a single-interface,
bound-redocking benchmark. Do not interpret its DockQ results as full
biological-assembly accuracy.
