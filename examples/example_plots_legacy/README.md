# Legacy Example Plots

This directory is retained as an **archival snapshot** of older example
plot exports.  It is not the current CLI plot contract and it is not
regenerated by the active example-plot workflow.

For the current fabricated plot gallery, use:

- `examples/example_plots/` for the maintained PNG outputs
- `examples/example_plots/fabricated_scores.tsv` for the synthetic scores
  table that now drives those plots

Treat the files in this legacy directory as historical reference only.
